## 3. Common Student Assessment

For every chart, students should complete these activities:

1. Identify the chart and explain its purpose.
2. Identify the type of data required.
3. Create the chart using the provided dataset.
4. Add an appropriate title, axis labels and legend.
5. Modify the chart's appearance.
6. Write three observations based on the chart.
7. Explain when this chart should be used instead of another chart.

## 2. Add three important teaching elements

These will make your lessons considerably stronger.

A. Common mistakes

Explain mistakes students should avoid.

Examples:

- Choosing the wrong chart type.
- Using misleading scales.
- Missing chart titles and labels.
- Using too many colors.
- Displaying inappropriate data.

B. When NOT to use this chart

Students should understand the limitations of each chart.

For example:

- Pie charts are difficult to interpret when there are too many categories.
- Line charts are generally unsuitable for unrelated categories.
- Bar charts are not the best choice for showing continuous data distributions.

C. Compare with another chart

Show students how the same or similar dataset can be represented differently and explain which visualization is more appropriate.

For example:

- Bar Chart vs Pie Chart
- Histogram vs Bar Chart
- Line Chart vs Area Chart
- Box Plot vs Violin Plot

My final advice: Use the 15-step structure as your master lesson template, but don't force every section into a separate lengthy explanation. Some charts, such as Pie and Bar Charts, can be taught relatively quickly, while Box Plots, Violin Plots and Contour Plots need more time.

This approach will help students learn three things: understand data, choose the right chart, and communicate meaningful information through visualization.
