## 19. Views and Materialized Views in PostgreSQL

Learn and practise how to create, retrieve data from, update, replace, rename, and drop PostgreSQL Views and Materialized Views. Understand the differences between them, how to refresh stored query results, and when to use each type.

| Practice Activity | Description |
|---|---|
| [MCQs](views/practice-and-progress/mcqs.md) | Test your understanding of Views, Materialized Views, SQL commands, refreshing, and practical query concepts. |
| [Practice Exercises](views/practice-and-progress/practice-exercises.md) | Practise creating and managing Views and Materialized Views using the `students` table and the DVD Rental database. |
| [Review Questions](views/practice-and-progress/review-questions.md) | Review key concepts, SQL syntax, differences, and practical applications of Views and Materialized Views. |
