# Prompt: Generate Programming Language Lab Exercises

Create a **beginner-friendly programming lab** for a **Programming Language course** using the following learning pattern for every exercise:

> **Example → Understand the Code → Modify the Code → Solve a Similar Task**

The lab must use the **exact output format specified below for every exercise**. Do not change, remove, or reorder the sections.

---

# Learning Pattern

For every exercise, follow these four stages:

1. **Example** — Show a simple working program.
2. **Understand the Code** — Explain how the program works.
3. **Modify the Code** — Students make guided changes to the existing program.
4. **Solve a Similar Task** — Students independently solve a new but related problem.

# Fixed Format Rules

For **EVERY exercise**, enforce the following rules:

* Use exactly the same section order.
* Do not skip any section.
* Do not add unrelated sections.
* Use the four-stage learning pattern:
  **Example → Understand the Code → Modify the Code → Solve a Similar Task**
* Every **Example** must contain complete working code.
* Every Example must contain **Input, Output, Code, and Expected Output**.
* Every **Modify the Code** section must contain exactly **3 modification tasks**.
* Every **Solve a Similar Task** section must contain:

  * Problem Statement
  * Input
  * Output
  * Requirements
  * Sample Input
  * Sample Output
* Do not provide the solution code for modification or independent tasks.
* The independent task should be slightly more challenging than the Example.
* Do not introduce programming concepts that have not yet been taught.
* Keep the difficulty appropriate for beginners.
* Use meaningful variable names.
* Explain code in simple language.
* Use **C++** unless another programming language is specified.

# Instructor Design Principle

Design the exercises so that students progressively move from:

**Seeing a working example**
↓
**Understanding how it works**
↓
**Changing an existing program**
↓
**Writing a similar program independently**

The goal is to make students **understand and construct programs**, rather than simply copy code.

Always maintain the same fixed structure for every exercise.
