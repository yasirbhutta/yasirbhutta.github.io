# Section 1: While Loop

## Problem Statement 1: Repeat a Message

Write a C++ program using a `while` loop to display your name five times.

## Problem Statement 2: Print a Sequence

Write a C++ program using a `while` loop to display numbers from 1 to 50.

## Problem Statement 3: Print Odd Numbers

Write a C++ program using a `while` loop to display all odd numbers from 1 to 25.

## Problem Statement 3: Countdown

Write a C++ program using a `while` loop to display numbers from 50 down to 1.

## Problem Statement 4: Calculate a Sum

Write a C++ program using a `while` loop to calculate and display the sum of numbers from 1 to 20.

## Problem Statement 5: Multiplication Table

Write a C++ program that asks the user to enter a number and uses a `while` loop to display its multiplication table from 1 to 10.
