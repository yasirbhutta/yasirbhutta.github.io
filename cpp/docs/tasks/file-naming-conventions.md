### 1. Create a Main Folder
Create one main folder named:

`CPP-Programming`

### 2. Create Topic-Wise Subfolders
Create a separate folder for each topic.

Example:

```text
CPP-Programming/
├── Topic-01-Escape-Sequences/
└── Topic-02-Input-Output-Manipulators/
```

### 3. Save Each Program with a Meaningful File Name
Use a separate C++ file for each example and coding exercise.

**Topic 1: Escape Sequences**
```text
Topic-01-Escape-Sequences/
├── Example-01.cpp
├── Example-02.cpp
└── Example-03.cpp
```

**Topic 2: Input and Output Manipulators**
```text
Topic-02-Input-Output-Manipulators/
├── Example-01.cpp
├── Example-02.cpp
├── Example-03.cpp
├── Exercise-01.cpp
└── Exercise-03.cpp
```

### 4. File Naming Rules
- Use meaningful and consistent file names.
- Use `.cpp` as the file extension.
- Use hyphens `-` instead of spaces.
- Number examples and exercises in order.
- Save each program in a separate file.
- Avoid names such as `new.cpp`, `test.cpp`, or `final2.cpp`.
