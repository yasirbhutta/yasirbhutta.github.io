## Question 3: Arithmetic Calculations

**Task:** Predict the output of each calculation.

### Code

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int b = 3;

    cout << a + b << endl;
    cout << a - b << endl;
    cout << a * b << endl;
    cout << a / b << endl;
    cout << a % b << endl;

    return 0;
}
```

## Question 4: Combining Variables and Operators

**Task:** Trace the code and predict the output.

### Code

```cpp
#include <iostream>
using namespace std;

int main()
{
    int x = 5;
    int y = 2;

    x = x + 3;
    y = y * 2;

    cout << x << endl;
    cout << y << endl;
    cout << x + y << endl;

    return 0;
}
```
