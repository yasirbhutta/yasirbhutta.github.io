# Learn Programming with AI Prompts

AI can support your programming practice by explaining concepts, asking guiding questions, and helping you find mistakes. Use it as a tutor, not as a replacement for writing and understanding your own code.

## A prompt for learning a new concept

> I am learning **[programming concept]** in **[programming language]** and I am a beginner. Explain the concept in simple steps, show a small example, and explain each line. Then give me one similar problem to solve without showing its solution. Wait for my attempt before giving feedback.

## A prompt for practicing a problem

> Give me a beginner-level **[programming concept]** problem in **[programming language]**. Do not show the solution yet. Ask me to explain my approach and write code. After I share my attempt, point out what works and give me one hint at a time if I am stuck.

## A prompt for understanding code

> Help me understand this code as a beginner. First ask me what I think it does. Then explain its purpose, trace it step by step, and clarify any unfamiliar syntax. Do not rewrite it unless I ask.
>
> **Code:**  
> [Paste your code here]

## A prompt for reviewing your solution

> Review my solution to **[problem]** in **[programming language]**. Check whether it meets the requirements and explain any errors or edge cases in simple terms. Give me hints to improve it before showing a complete solution.
>
> **Problem:** [Describe the problem]  
> **My solution:** [Paste your code here]

## Make your prompts more useful

- Name the language, topic, and your current level.
- Share the exact code and error message when asking for debugging help.
- Ask for explanations or hints before asking for a complete solution.
- Run the code yourself and check that you understand the result.
- Never share passwords, private keys, or other sensitive information in a prompt.
