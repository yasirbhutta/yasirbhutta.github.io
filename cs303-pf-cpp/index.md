# C++ Programming Tasks

## Guidelines for Folder and File Names

### 1. Create a Main Folder
Create one main folder named:

`CPP-Programming`

### 2. Create Topic-Wise Subfolders
Create a separate folder for each topic.

Example:

```text
CPP-Programming/
├── Topic-01-Escape-Sequences/
└── Topic-02-Input-Output-Manipulators/
```

### 3. Save Each Program with a Meaningful File Name
Use a separate C++ file for each example and coding exercise.

**Topic 1: Escape Sequences**
```text
Topic-01-Escape-Sequences/
├── Example-01.cpp
├── Example-02.cpp
└── Example-03.cpp
```

**Topic 2: Input and Output Manipulators**
```text
Topic-02-Input-Output-Manipulators/
├── Example-01.cpp
├── Example-02.cpp
├── Example-03.cpp
├── Exercise-01.cpp
└── Exercise-03.cpp
```

### 4. File Naming Rules
- Use meaningful and consistent file names.
- Use `.cpp` as the file extension.
- Use hyphens `-` instead of spaces.
- Number examples and exercises in order.
- Save each program in a separate file.
- Avoid names such as `new.cpp`, `test.cpp`, or `final2.cpp`.

## Topic 1: Escape Sequences in C++ - Input and Oupt

### Tasks

1. **Learn:** Understand the purpose of common C++ escape sequences, including `\n`, `\t`, `\\`, `\"`, `\'`, and `\r`.
2. **Practice:** Write and run Examples 1–3
3. **Modify:** Change the code and observe how the output changes.
4. **Verify Output:** Make sure each program compiles and produces the expected output.

### Submission and Checking

- **Checking:** All 3 examples will be checked on your mobile phone or laptop.

**Note:** Complete all tasks before the due date and keep your programs ready for checking.
